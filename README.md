# Совместная игра: сервер

Все, кто открыл страницу, видят одну и ту же карту: когда кто-то двигает фишку, остальные видят это сразу.

## Что где лежит

```
server.js            сервер (раздача игры + синхронизация), без зависимостей
public/index.html    сама игра (та же, что game_lite.html, + 2 мелкие правки для синхронизации)
public/multiplayer.js  клиентская часть синхронизации
data/state.json      создаётся сам: сохранённые позиции фишек (переживает перезапуск)
test/                проверки (необязательно)
Dockerfile           для запуска в Docker
```

## Запуск (1 минута)

Нужен только [Node.js](https://nodejs.org) версии 16 или новее. Устанавливать пакеты не нужно.

```
cd multiplayer-server
node server.js
```

В консоли появится адрес:

```
Игра запущена:  http://localhost:3000
Для других в вашей сети:  http://192.168.1.15:3000
```

- Сам откройте `http://localhost:3000`.
- Друзья в той же Wi-Fi/локальной сети открывают адрес из строки «Для других в вашей сети».
- В левом верхнем углу игры появится метка **🟢 Онлайн: N**: сколько людей подключено.

Порт можно сменить: `PORT=8080 node server.js` (Windows PowerShell: `$env:PORT=8080; node server.js`).

## Как пригласить людей не из вашей сети

**Вариант 1. Временная ссылка с вашего компьютера** (проще всего, пока играете):

```
cloudflared tunnel --url http://localhost:3000
```

(или `ngrok http 3000`). Они выдадут адрес вида `https://что-то.trycloudflare.com`: отправьте его друзьям.
Работает, пока запущены и сервер, и туннель.

**Вариант 2. Постоянный хостинг.** Подойдёт любой, где можно запустить Node.js или Docker с поддержкой WebSocket
(Render, Railway, Fly.io, обычный VPS). Команда запуска: `node server.js`. Порт хостинг обычно задаёт через `PORT`: сервер его подхватывает.
Если хостинг не хранит файлы между перезапусками, позиции фишек после перезапуска сбросятся. Это не страшно.

Если ставите свой VPS за nginx, нужны заголовки для WebSocket:

```
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;
}
```

Игра сама выбирает `ws://` или `wss://` по тому, как открыта страница (http/https), ничего настраивать не нужно.

## Что синхронизируется

- Позиция и этаж 4 основных персонажей (Агнес, Изабелла, Кармелита, Мэгги).
- Свои фишки: создание, удаление, перемещение (с именами и цветами).
- Новый игрок сразу видит текущее положение всех фишек.

У каждого **своё** (не синхронизируется): какой персонаж выбран, положение камеры и масштаб, освещение, список локаций.

**Важно:** договоритесь, кто каким персонажем управляет. Если двое одновременно выберут одного и того же персонажа, он будет «дёргаться»: побеждает тот, кто двигал последним. Самодельные фишки можно двигать любому.

## Сброс и администрирование

- Сбросить все позиции: остановить сервер и удалить `data/state.json`.
- Или, не останавливая сервер: запустите его с ключом `ADMIN_KEY=мойключ node server.js` и откройте `http://адрес/reset?key=мойключ`. Мир зададут заново позиции того, кто подключится первым.
- Посмотреть текущее состояние: `http://адрес/state`. Проверка живости: `http://адрес/health`.

## Если что-то не работает

- **Метка «🔴 Нет связи»**: страница открыта не через сервер. Открывайте игру по адресу `http://…`, а не двойным кликом по файлу.
- **Метка «⚪ Открыто как файл»**: то же самое. Для теста с другим сервером можно добавить `?server=адрес:порт` к ссылке.
- **Друзья не могут открыть адрес из локальной сети**: разрешите Node.js во входящих подключениях брандмауэра.
- **Первая загрузка долгая**: файл игры около 20 МБ (сервер отдаёт его в сжатом виде, около 14 МБ). Дальше браузер берёт его из кэша.

## Проверки (по желанию)

Сервер запущен в одном окне, в другом:

```
node test/smoke.js ws://localhost:3000/ws      # проверка протокола и защиты от мусора
node test/client-sim.js localhost:3000         # проверка клиентской синхронизации на имитации игры
```

Запускайте проверки на свежем сервере (без сохранённого состояния), иначе часть сценариев начнётся с чужих позиций.
